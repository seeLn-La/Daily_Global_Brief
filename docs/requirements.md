# 项目需求文档

## 项目定位

面向商业分析从业者的全球新闻聚合系统，聚焦科技、商业、AI 发展三大领域，通过精准新闻聚合助力用户洞察世界发展趋势。

## 核心功能

### 一、新闻模块分类

固定三大模块，每模块每日更新 10 条代表性新闻：

| 模块         | 英文标识       | 说明               |
| ------------ | -------------- | ------------------ |
| 科技模块     | Technology     | 全球科技行业动态   |
| 商业模块     | Business       | 全球商业财经资讯   |
| AI 发展模块  | AI Development | AI 行业与研究进展  |

### 二、新闻呈现要求

- **内容限制**：单条新闻摘要 ≤ 30 字，中英文双语展示
- **附加信息**：每条新闻绑定原始链接，支持点击跳转查看详情
- **整理逻辑**：按日期倒序排列，默认展示当日，支持历史日期查询

### 三、推送需求

- 每日早上 **8:00（北京时间）** 准时推送到手机
- 推送渠道：Bark App（iOS）
- **每日执行不消耗 AI/LLM Token**

### 四、UI 设计需求

- 风格：极简主义，参考 Apple 官网设计
- 色彩：黑白灰为基调，Apple 蓝色作为强调色
- 布局：模块分区明确，操作路径简单
- 字体：SF Pro Display / system-ui

## 约束条件

- 每日自动运行不消耗任何 AI/LLM API Token
- 部署在 GitHub Actions + GitHub Pages（免费）
- 新闻来源通过公开 RSS 抓取
- 翻译使用免费开源库（deep-translator）
